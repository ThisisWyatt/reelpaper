# reelPaper UI 重设计 —— 设计规格文档

> 目标：将 mpvRx 播放器应用的 UI 全面重构为 SmartisanOS 拟物风格（纸与墨的质感语言）。
> 策略：主题系统重构优先，自上而下推进。

---

## 1. 设计哲学

### 1.1 质感语言：纸 · 墨 · 朱砂

- **纸**（#F3EDE0）— 温暖、可触摸的背景基底
- **墨**（#3C362C）— 清晰、沉稳的信息承载
- **朱砂**（#B23129）— 精确、克制的操作强调

### 1.2 海拔规则

| 层级 | 名称 | 用途 | 视觉特征 |
|------|------|------|----------|
| ① | 卡纸浮起 (--raise) | 卡片、胶囊、迷你键 | 柔和上浮阴影 |
| ② | 纸槽内凹 (--inset) | 输入槽、滑轨、激活 Tab | 内凹阴影，边缘微暗 |
| ③ | 实体键台阶 | 矩形可按压主操作键 | 底部均匀厚度阴影，按下 translateY |
| 特殊 | 软浮双层投影 | 圆形键（FAB / 播放键） | 禁用台阶（圆形剪影=月牙），改用双层柔影 |
| 特殊 | 珐琅软浮 | Logo 徽章 | 无台阶，精致光泽边框 |
| 特殊 | 叠纸错位 | 播放列表卡片 | 故意微旋错位，形成一叠纸的隐喻 |

### 1.3 全局纹理

- 全局纸纹噪点叠加（7% 透明度），使用 SVG fractalNoise 或预生成纹理 Bitmap
- 深色主题下噪点增强至 9%
- 屏幕顶部有径向渐变光泽（模拟纸张反光）

## 3. 核心组件库

### 3.1 悬浮纸坞 TabBar

- **尺寸**：宽 286dp，高 58dp，圆角 18dp，位于底部中央
- **结构**：4 个标签页（主页 / 播放列表 / 快照 / 网络）
- **非激活态**：仅显示图标，灰色（Ink3）
- **激活态**：
  - 图标变为朱砂色
  - 键身切换为内凹纸槽样式（PaperInset + Inset 阴影）
  - 右侧弹性展开文字标签（max-width 0 → 38dp）
  - flex-grow 从 1 → 1.85 同步占位
- **切换动画**：0.32s，cubic-bezier(0.45, 1.25, 0.4, 1)
- **隐藏控制**：外观设置中可逐个关闭标签页，关闭后纸坞对应键消失

### 3.2 按钮系统

#### 朱砂实体键（矩形主操作键）
- 高度 50dp，圆角 13dp
- 朱砂渐变背景（上亮下暗）
- 底部 3dp 台阶阴影（CinnabarDk）
- 按下：translateY(2dp)，阴影收缩

#### 卡纸按钮（次级操作键）
- 高度 48dp，圆角 12dp
- 卡纸渐变背景
- 浮起阴影
- 按下：translateY(1dp) 变内凹

#### 朱砂圆键 FAB（圆形）
- 直径 56dp
- 禁用台阶（圆形剪影=月牙→蛋形）
- 软浮双层投影
- 按下：translateY(2dp) + 阴影收缩

#### 图标按钮
- 40×40dp，圆角 12dp
- 透明背景，灰色图标
- 按下：背景变 Press 色 + 内凹阴影

### 3.3 拨杆开关

- 轨道：48×29dp，圆角 15dp，纸槽内凹样式
- 滑块：24×24dp 圆形，纸色渐变，带微投影
- 开启态：轨道变为朱砂渐变，滑块右移（弹性回弹动画）
- 迷你版：40×24dp，滑块 19×19dp

### 3.4 卡片系统

#### 通用列表卡片
- 圆角 14dp，卡纸背景，浮起阴影
- 内部行：图标槽（38dp 圆角 11dp，内凹）+ 标题 + 副标题 + 可选操作
- 行之间细线分隔（Line 色）

#### 叠纸卡片（播放列表专用）
- 主卡片浮起，下方故意露出两层错位微旋的卡片边缘
- 第一层：translate(4dp, 4dp) rotate(0.7°)
- 第二层：translate(8dp, 8dp) rotate(-0.6°)，透明度 75%
- 形成"一叠纸"的视觉隐喻

### 3.5 搜索槽

- 高度 42dp，圆角 12dp
- 纸槽内凹样式
- 左侧搜索图标 + 输入区 + 可选清除图标

### 3.6 分段控件

- 纸槽内凹背景，圆角 12dp
- 选项：圆角 9dp，选中时卡纸背景 + 浮起阴影

### 3.7 弹窗系统

#### 底部 Sheet
- 圆角 18dp，卡纸背景
- 顶部有细白线高光（inset 0 1px 0 rgba(255,255,255,0.7)）
- 弹出动画：scale(0.9) translateY(14dp) → 正常，0.3s 弹性缓出
- 遮罩：半透明暖棕色 + 轻微模糊

#### 表单（弹窗内）
- 卡纸背景卡片，圆角 14dp
- 表单项：标签（小字，淡墨，letter-spacing 2px）+ 输入槽
- 双列布局支持（如服务器地址+端口）

### 3.8 滑杆

- 轨道：纸槽内凹，6dp 高度，圆角 4dp
- 填充：朱砂渐变
- 滑块：16dp 圆形，纸色渐变，带投影

## 4. 页面设计

### 4.1 主页（文件夹列表）

**顶栏**：
- 左侧：胶片盘 Logo 徽章（34dp，珐琅软浮）+ 应用名 "reelPaper"（衬线斜体）+ 副标题 "私人视频播放器"
- 右侧：搜索 / 排序与视图 / 设置 图标按钮

**内容**：
- 搜索槽（内凹）
- 分区标题："全部文件夹" + 右侧视频总数
- 文件夹列表（列表/网格可切换）
  - 列表态：文件夹图标 + 名称 + 视频数量 + 右箭头
  - 网格态：文件夹图标放大 + 名称在下方
  - 新文件夹角标（红色气泡）
- 底部留出纸坞空间（dockpad）

**弹窗**：排序与视图
- 排序方式（标题/日期/大小/数量）
- 排序顺序（升序/降序）
- 视图模式（文件夹/树形/媒体库）
- 布局（列表/网格）
- 选项：仅应用于文件夹列表 / 手动调整网格
- 网格列数步进器（2-4）

### 4.2 文件/播放列表详情页

- 视频列表（列表/网格可切换）

**添加视频弹窗**：

## 5. 播放器重构

### 5.1 竖屏播放器

**视频区**（216dp 高度）：
- 暖色渐变背景（模拟视频暂停时的占位），带径向光晕装饰（bk1/bk2 模糊圆）
- 顶部渐变遮罩 + 标题/副标题
- 中央播放按钮：74dp 圆形，毛玻璃效果（半透明 + 轻微模糊），播放时淡出并放大
- 右下角时长角标
- 左/右半屏快退/快进提示文字（仅在横屏显示）

**信息区**：
- 文件格式信息（MP4 · 1920×1080 · 30fps · 立体声）
- 操作按钮：截图 / 投屏 / 收藏

**播放队列**：
- 同文件夹视频列表
- 当前项：红色左边缘标记 + 均衡器动画（三根跳动的朱砂条）
- 其他项：播放按钮

**控制区**：
- 进度滑杆：纸槽轨道 + 朱砂填充 + 纸色滑块
- 主控制：锁定 / 快退 / 播放暂停 / 快进 / 全屏
- 功能芯片：速度 / 音轨 / 字幕 / 循环
- 手势提示文字

### 5.2 横屏播放器

- 视频区全屏，控制层悬浮
- 首次进入横屏：弹出播放器手势说明卡
  - 双击左/右半屏 = 快退/快进
  - 左半屏上下滑 = 亮度
  - 右半屏上下滑 = 音量
- 手势指示浮层：
  - 亮度：左侧，暖色渐变条
  - 音量：右侧，绿色渐变条
  - 中央百分比数字
- 底部控制条：半透明渐变背景，简化按钮

## 7. 技术架构决策

### 7.1 与现有系统的集成

- **直接替换默认主题**：不再保留 Material 3 默认外观，全面替换为拟物风格
- **保留主题切换动画**：现有的涟漪揭示动画继续工作
- **保留动态壁纸支持**：AppWallpaperHost 继续工作，但纸纹噪点叠加在壁纸之上
- **保留 Edge-to-Edge**：系统栏颜色同步调整（浅色 #F7F5F8 / 深色 #161217）

### 7.2 实现顺序

1. **主题系统**：颜色、字体、阴影、纹理
2. **核心组件**：按钮、卡片、输入框、开关、弹窗、滑杆
3. **导航组件**：悬浮纸坞、AppBar
4. **页面重构**：主页 → 文件详情 → 播放列表 → 快照 → 网络 → 设置
5. **播放器重构**：竖屏 → 横屏 → 手势系统
6. **动画 polish**：页面切换、纸坞动画、按压反馈

### 7.3 兼容性

- 保持所有现有功能不变（选择模式、多选、拖拽排序、画中画等）
- 保持现有 ViewModel 和数据流不变
- 仅修改 UI 层（Composable 函数和主题配置）

## 8. 风险与注意事项

1. **纸纹噪点性能**：全局纹理叠加可能影响低端设备性能，需提供开关或降级方案
2. **阴影渲染**：复杂的多层阴影在 Compose 中可能需要自定义绘制，注意性能
3. **字体兼容性**：衬线体在某些语言/设备上可能不可用，需设置合理的 fallback
4. **AMOLED 纯黑**：确保纯黑模式下对比度足够，文本可读
5. **横屏适配**：横屏下的布局需要充分测试，特别是纸坞和迷你播放器的位置
