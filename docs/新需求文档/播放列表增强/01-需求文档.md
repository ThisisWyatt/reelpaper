# 播放列表网络视频支持 — 需求文档

## 1. 背景与目标

### 1.1 背景

mpvRx 的持久化播放列表（Playlists Tab）目前仅支持添加本地视频文件（`content://`、`file://` 及本地绝对路径）。用户无法将网络存储（WebDAV/SMB/FTP/SFTP）中的视频文件添加至普通播放列表中，只能直接播放或导入为独立的 M3U 播放列表。

### 1.2 目标

支持将网络连接（WebDAV 等）中的视频文件添加到**现有的普通播放列表**中，并在网络连接不可用（断开、删除、认证失败等）时，保持播放列表的完整展示与友好的用户提示。

---

## 2. 需求范围

### 2.1 In Scope（范围内）

- 普通播放列表（`isM3uPlaylist = false`）添加网络视频文件
- 支持的网络协议：WebDAV、SMB、FTP、SFTP（复用现有网络连接体系）
- 网络连接断开/不可用时，播放列表详情页的展示与交互策略
- 网络视频缩略图在断连后的缓存展示
- 无网络连接配置时的引导流程

### 2.2 Out of Scope（范围外）

- 单个裸 URL（直链）添加到普通播放列表（暂不支持）
- M3U 播放列表导入（已有功能，不涉及改造）
- 网络视频的在线元数据自动更新（如文件名变更同步）
- 离线缓存/下载网络视频到本地

---

## 3. 功能需求

### 3.1 FR-01：播放列表添加视频入口支持网络来源

**描述**：在 `PlaylistAddVideosScreen` 中，用户切换至"网络连接"来源后，可浏览已保存的网络连接并选择视频文件添加到当前播放列表。

**验收标准**：
- 顶部提供 `[本地媒体 | 网络连接]` 来源切换
- "网络连接"Tab 展示已保存的连接列表（复用 `NetworkConnectionCard`）
- 点击连接进入文件浏览器，支持多选视频文件
- 选择完成后，视频条目持久化到当前播放列表

### 3.2 FR-02：无网络连接时的空状态引导

**描述**：当用户切换到"网络连接"来源，但尚未配置任何连接时，展示空状态并引导用户创建连接。

**验收标准**：
- 展示空状态图标 + 文案（复用现有 `EmptyStateCard` 风格）
- 提供"添加连接"按钮，点击弹出 `AddConnectionSheet`
- 创建连接后自动进入该连接的浏览界面

### 3.3 FR-03：网络文件在播放列表中的持久化存储

**描述**：网络视频文件添加到播放列表后，其信息以兼容现有播放体系的方式持久化存储。

**验收标准**：
- 使用 `NetworkPlaybackUri` 格式存储（如 `network://{connectionId}/path/to/video.mp4`）
- 数据库 `PlaylistItemEntity` 新增 `connectionId` 字段标识网络来源
- 播放器端无需改造即可解析并播放（复用现有代理体系）

### 3.4 FR-04：断连后播放列表完整展示

**描述**：当网络连接不可用（服务器离线、连接被删除、认证失败等）时，已添加的网络视频条目仍在播放列表中完整展示，包括已缓存的缩略图。

**验收标准**：
- 列表项名称、缩略图（如有缓存）、已保存的元数据正常显示
- 不做大幅度视觉降级（不降低透明度、不灰显）
- 可附加极 subtle 的离线标识（如右下角小圆点或 `CloudOff` 图标），也可完全无标识
- 不自动删除或隐藏不可用的条目

### 3.5 FR-05：点击不可用条目的友好提示

**描述**：用户点击当前不可用的网络视频条目时，给出明确的不可用原因提示，并提供后续操作选项。

**验收标准**：
- 不直接跳转播放器或崩溃
- 以 `Snackbar` 形式提示，如："「视频名称」所在连接当前不可用"
- Snackbar 提供"移除"操作按钮，用户可手动从播放列表删除该条目
- 可选提供"重试"或"检查连接"入口

### 3.6 FR-06：本地文件不存在时统一处理

**描述**：借机统一优化现有逻辑——本地文件被移动/删除后，播放列表中的条目也应获得与网络文件一致的不可用提示体验。

**验收标准**：
- 本地文件 `!file.exists()` 时，同样标记为 `isAvailable = false`
- 视觉上与网络不可用条目保持一致
- 点击时提示"文件已被移动或删除"

---

## 4. 非功能需求

### 4.1 性能

- 播放列表加载时不因网络探测而阻塞（懒检测策略）
- 缩略图加载优先走缓存，不触发网络请求

### 4.2 兼容性

- 数据库变更需通过 Room Migration 实现，兼容现有用户数据
- 播放器端完全复用现有 `NetworkPlaybackUri` + `NetworkStreamingProxy` 体系，不引入新播放逻辑

### 4.3 用户体验

- 网络文件添加流程应与本地文件添加流程体验一致（Folder → Video → 多选确认）
- 不可用的条目不应给用户"数据丢失"的恐慌感

---

## 5. 边界情况

| 场景 | 预期行为 |
|------|---------|
| 连接被删除 | 条目仍展示，标记为不可用，点击提示"连接配置已被删除" |
| 服务器离线 | 条目仍展示，标记为不可用，点击提示"网络连接不可用" |
| 认证失败（密码变更） | 条目仍展示，标记为不可用，点击提示"认证失败" |
| 服务器上文件被移动 | 条目仍展示，播放时通过代理返回 404，播放器提示失败 |
| 缩略图未缓存且断连 | 显示默认占位图（与本地文件无缩略图时一致） |
| 播放列表混合本地+网络 | 本地正常展示，网络条目按上述策略展示，互不影响 |

---

## 6. 相关模块

- `ui/browser/playlist/PlaylistAddVideosScreen` — 添加视频入口
- `ui/browser/playlist/PlaylistDetailScreen` — 播放列表详情展示
- `ui/browser/playlist/PlaylistDetailViewModel` — 列表加载与可用性判断
- `ui/browser/networkstreaming/NetworkBrowserScreen` — 网络文件浏览器（需扩展选择模式）
- `database/entities/PlaylistItemEntity` — 数据模型
- `database/repository/PlaylistRepository` — 播放列表仓库
- `domain/thumbnail/ThumbnailRepository` — 缩略图缓存
- `ui/player/PlayerActivity` + `NetworkStreamingProxy` — 播放（无需改动）
