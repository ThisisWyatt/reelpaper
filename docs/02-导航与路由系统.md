# 导航与路由系统

> 本文档基于 `ui/utils/ScreenNavigation.kt`、`presentation/Screen.kt` 及相关 Composable 源码分析得出。
> 无法从代码确认的信息标注【待确认】。

---

## 1. 技术选型

mpvRx 使用 **Jetpack Navigation3**（版本 1.1.7，由 `libs.versions.toml` 确认）作为导航框架，而非传统的 Navigation Compose（`androidx.navigation:navigation-compose`）。

**关键差异**：
- Navigation3 使用**基于类的路由**（`@Serializable data class` 实现 `Screen` 接口），而非字符串路由
- 类型安全：编译期保证参数类型正确
- 与 Kotlinx Serialization 深度集成

## 2. 核心抽象

### 2.1 Screen 接口

```kotlin
interface Screen {
  @Composable
  fun Content()
}
```

所有可导航屏幕均为 `Screen` 接口的实现类，通过 `@Serializable` 支持序列化。

### 2.2 路由定义示例

```kotlin
@Serializable
data class NetworkBrowserScreen(
  val connectionId: Long,
  val connectionName: String,
  val currentPath: String = "/",
) : Screen {
  @Composable
  override fun Content() {
    // Composable 实现
  }
}
```

```kotlin
@Serializable
data class PlaylistDetailScreen(
  val playlistId: Int,

  @Composable
  override fun Content() { ... }

```

```kotlin

  val uri: String,
```

## 3. 导航宿主架构

### 3.1 根导航器

`MainActivity` 的 `setContent` 中设置根导航器：

```kotlin
class MainActivity : AppCompatActivity() {
  override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    setContent {
      MpvrxTheme {
        Navigator()  // 根导航器 Composable
      }
    }
  }
}
```

### 3.2 导航器实现（ScreenNavigation.kt）

```kotlin
@Composable
fun Navigator() {
  val backStack = rememberSaveableBackStack(initial = HomeScreen)
  val navigator = rememberNavigator(backStack)

  CompositionLocalProvider(LocalBackStack provides backStack) {
    NavigableScaffold(
      navigator = navigator,
      backStack = backStack,
    ) {
      // 路由分发
    }
  }
}
```

**关键组件**：

| 组件 | 类型 | 职责 |
|------|------|------|
| `rememberSaveableBackStack` | `BackStack<Screen>` | 维护导航栈状态，支持配置变更恢复 |
| `rememberNavigator` | `Navigator` | 执行导航操作（push、pop、replace） |
| `LocalBackStack` | `CompositionLocal` | 向子树提供当前 BackStack |

### 3.3 回退栈操作

```kotlin
// 获取当前 BackStack
val backstack = LocalBackStack.current

// 导航到目标屏幕
backstack.navigateTo(NetworkBrowserScreen(connectionId = 42, connectionName = "NAS"))

// 安全返回（栈空时不崩溃）
backstack.popSafely()
```

**扩展方法**（`ui/utils/ScreenNavigation.kt`）：

```kotlin
fun BackStack<Screen>.navigateTo(screen: Screen) {
  push(screen)
}

fun BackStack<Screen>.popSafely() {
  if (canPop) pop()
}
```

## 4. 底部导航与标签页

### 4.1 主屏幕结构

应用主界面采用 **底部导航栏（Bottom Navigation）+ 独立回退栈** 的设计：

```
┌─────────────────────────────────────────┐
│           顶部 AppBar / 标题              │
├─────────────────────────────────────────┤
│                                         │
│         当前标签页的内容区域              │
│         （独立的 BackStack）              │
│                                         │
├─────────────────────────────────────────┤
│  [本地]   [网络]   [播放列表]   [设置]   │
│   🎬      🌐       📋         ⚙️        │
└─────────────────────────────────────────┘
```

### 4.2 标签页定义

```kotlin
enum class MainTab(
  val labelRes: Int,
  val icon: ImageVector,
  val rootScreen: Screen,
) {
  LOCAL(R.string.tab_local, Icons.Filled.Local, LocalMediaScreen),
  NETWORK(R.string.tab_network, Icons.Filled.Network, NetworkStreamingScreen),
  PLAYLISTS(R.string.tab_playlists, Icons.Filled.Playlist, PlaylistsScreen),
  SETTINGS(R.string.tab_settings, Icons.Filled.Settings, SettingsScreen),
}
```

### 4.3 标签页切换策略

- 每个标签页拥有**独立的 `BackStack`**
- 切换标签页时，当前标签页的 BackStack 被保留
- 返回手势优先处理当前标签页的内部导航；若当前标签页栈空，则处理系统返回

## 6. 返回处理

### 6.1 系统返回键

```kotlin
@Composable
fun NavigationBackHandler(onBack: () -> Unit) {
  val backCallback = remember {
    object : OnBackPressedCallback(true) {
      override fun handleOnBackPressed() = onBack()
    }
  }
  // 注册到 OnBackPressedDispatcher
}
```

### 6.2 嵌套返回处理

在 `NetworkBrowserScreen` 中的典型处理：

```kotlin
BackHandler {
  if (isSearching) {
    isSearching = false
    searchQuery = ""
  } else {
    backstack.popSafely()
  }
}
```

**优先级**：局部 `BackHandler` 优先于全局返回。搜索状态打开时，返回键先关闭搜索，再退出页面。

## 7. 深层链接与外部启动

### 7.1 PlayerActivity 的 Intent 过滤

`PlayerActivity` 支持多种外部启动方式：

```xml
<activity android:name=".ui.player.PlayerActivity">
  <intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <data android:scheme="content" />
    <data android:scheme="file" />
    <data android:scheme="http" />
    <data android:scheme="https" />
    <data android:scheme="mpvrx-network" />
  </intent-filter>
</activity>
```

### 7.2 内部播放启动

```kotlin
// NetworkBrowserViewModel 中的典型启动
val intent = Intent(Intent.ACTION_VIEW, uri)
intent.setClass(application, PlayerActivity::class.java)
intent.putExtra("internal_launch", true)
intent.putExtra("launch_source", "network_stream")
intent.putExtra(PlayerActivity.EXTRA_PREPARED_PLAYBACK_QUEUE, true)
intent.putExtra(PlayerActivity.EXTRA_PREPARED_PLAYBACK_TOKEN, launchToken)
intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
application.startActivity(intent)
```

**注意**：`PlayerActivity` 的导航独立于 Navigation3 系统，属于 Activity 级别的页面跳转。
