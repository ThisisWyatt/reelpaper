# mpvRx 业务功能清单

> 本文档基于项目源码逐模块梳理，所有功能点均从代码中提取。无法从当前阅读范围确认的细节标注为【待确认】。

## 一、媒体库与本地浏览

### 1.1 本地媒体浏览
- **视频文件浏览**：基于 Android MediaStore 扫描本地视频文件，支持列表/网格/相册视图切换
- **音频文件浏览**：独立的音乐库标签页，支持歌曲/专辑/艺术家/播放列表/文件夹五种视图
- **文件夹导航**：树状目录浏览，支持自动扁平化单个子文件夹（可配置 flatten 深度：关闭/1层/2层/无限）
- **缩略图生成**：智能缩略图模式（按文件大小选择策略），支持高质量模式；自定义缩略图截取帧位置（默认 33%）
- **元数据展示**：文件时长、大小、分辨率、帧率、字幕指示器、编解码器支持指示器（部分默认关闭以优化性能）
- **进度记忆**：已观看进度条显示，已观看阈值可配置（默认 95%）
- **未播放标记**：超过配置天数（默认 7 天）未播放的视频显示"旧视频"标签
- **自动滚动**：支持自动滚动到最后播放的媒体位置（MX Player 风格）
- **扩展名显示**：可选显示文件扩展名字段

### 1.2 排序与布局
- **文件夹排序**：按标题/日期/大小/视频数量排序，升序/降序
- **视频排序**：按标题/时长/日期/大小排序，升序/降序
- **网格列数**：横竖屏独立配置网格列数，支持平板自适应（平板最多 8 列，手机最多 4 列）
- **视图模式**：列表/网格视图切换，文件夹视图和视频视图可独立配置布局模式
- **封面尺寸**：音乐列表封面尺寸、网格封面尺寸可配置

### 1.3 文件操作
- **删除**：删除文件或文件夹（可选删除文件夹内全部内容或仅媒体文件）
- **选择模式**：多选操作，支持仅视频选择时显示特定操作
- **缩略图点击选择**：可选启用缩略图点击即进入选择模式

## 二、网络播放与流媒体

### 2.1 网络存储协议支持
- **WebDAV**：基于 Sardine (OkHttpSardine) 的 WebDAV 客户端，支持 HTTP/HTTPS、Basic Auth/匿名访问
- **SMB/CIFS**：SMB/CIFS 网络存储浏览与播放
- **FTP**：基于 Apache Commons Net FTPClient 的 FTP 客户端
- **SFTP**：基于 JSch 的 SFTP 客户端，支持并发 Range 流（每个流独立 ChannelSftp）
- **自动连接**：启动后自动连接标记为"自动连接"的已保存网络共享
- **网络书签**：独立的网络书签偏好设置

### 2.2 网络播放代理架构
- **本地回环代理**：基于 NanoHTTPD 的 127.0.0.1 随机端口代理服务器
- **Capability Token**：24 字节密码学随机 Token 鉴权，URL 格式为 `http://127.0.0.1:{port}/{token}{path}`
- **无凭证 URI**：自定义 scheme `mpvrx-network://{connectionId}{path}`，URI 中不包含任何凭证信息
- **Range 请求支持**：支持 HTTP Range 请求，服务端自动处理 Range 解析与 206 Partial Content 响应；对返回 200 的服务器自动降级为 skip 策略
- **三级大小探测**：PROPFIND → HEAD Content-Length → Range: bytes=0-0 Content-Range 三级 fallback 探测文件大小
- **代理超时**：75 秒无活动后自动注销流

### 2.3 HLS 与在线流
- **HLS 代理**：HlsStreamingProxy 基于 NanoHTTPD 的 HLS 流代理（用于 M3U8 播放）
- **M3U 播放列表导入**：支持 M3U/M3U8 播放列表文件解析与导入，自动判断是否需要 HLS 代理
- **Xtream Codes 代理**：XtreamStreamingProxy 支持 Xtream Codes IPTV 流播放
- **Intent 接收**：可选启用 Web 流媒体链接 Intent 接收（WebStreamLinksActivityAlias）

### 2.4 凭证安全
- **AES-256-GCM 加密**：网络连接密码使用 AES-256-GCM 加密存储
- **Android Keystore**：加密密钥保存在 Android Keystore 中
- **明文迁移**：旧版本明文密码自动检测并迁移到加密存储

## 四、在线流媒体与下载

### 4.1 yt-dlp 集成
- **在线视频解析**：集成 yt-dlp 解析 1000+ 网站的视频流
- **播放质量选择**：质量偏好（-1 为任意）、编解码器偏好（H.264/HEVC/AV1/VP9 等）、最大帧率、HDR 偏好
- **音频偏好**：音频编码偏好、音频质量偏好
- **容器格式**：MP4/MKV/WebM 等容器偏好
- **字幕下载**：自动下载字幕、自动生成的字幕、字幕语言选择
- **SponsorBlock**：支持 SponsorBlock 标记和移除片段
- **直播支持**：可选从直播开始处播放
- **播放列表模式**：处理播放列表的方式（默认/仅首视频/全部）
- **高级配置**：自定义 User-Agent、Referer、Cookie 文件、代理、提取器参数、地理绕过、原始选项

### 4.2 下载引擎
- **yt-dlp 下载服务**：YtdlpDownloadService 后台下载
- **直链下载**：DirectDownloadService 支持直链文件下载
- **下载位置**：用户可配置 SAF 下载目录，默认使用应用私有目录
- **媒体合并**：YtdlpMediaMerger 处理音视频分离下载后的合并
- **下载管理**：下载队列管理、进度显示

## 五、Torrent 播放

### 5.1 引擎与协议
- **libtorrent4j**：基于 libtorrent4j 的 BitTorrent 引擎
- **元数据解析**：Torrent 文件和 Magnet 链接解析
- **文件选择**：TorrentSelectionScreen 支持选择要播放的单个文件
- **流式播放**：顺序下载优先策略，支持边下边播
- **本地代理**：TorrentProxyServer 为 libmpv 提供本地 HTTP 代理访问下载中的文件

### 5.2 播放集成
- **播放队列集成**：PlaybackItem 支持 torrentFileIndex 字段，支持多文件 Torrent 的剧集连续播放
- **Intent 接收**：通过 TorrentSelectionActivity 接收 Torrent 文件/Magnet 链接 Intent

## 六、播放核心与引擎

### 6.1 解码与渲染
- **libmpv 引擎**：基于 libmpv 原生核心的播放引擎
- **解码器切换**：Auto-Copy / Auto / SW / HW / HW+ 五种解码器模式
- **渲染后端**：OpenGL ES（默认）/ Vulkan（可选，设备支持时可用）
- **GPU-NEXT**：可选启用 GPU-NEXT 渲染管线
- **MPV 配置文件**：Fast / Default / High Quality / GPU HQ / Low Latency / SW Fast 六种预设

### 6.2 视频处理
- **视频滤镜预设**：12 种快速滤镜预设（无效果、鲜艳、暖色调、冷色调、柔和粉彩、电影感、戏剧、夜间模式、怀旧、吉卜力风格、霓虹流行、深黑）
- **手动滤镜调节**：亮度、饱和度、对比度、伽马、色调（范围 -100~100）、锐度（范围 -10~10）
- **Deband（色带去除）**：CPU / GPU 模式，参数可调（迭代次数、阈值、范围、颗粒度）
- **Anime4K 超分**：实时动漫超分辨率，支持多种模式、质量等级，可选 4K 模式、暗化、细化、去模糊
- **自动裁切黑边**：auto-crop 功能检测并裁切视频黑边

### 6.3 HDR 支持
- **HDR 屏幕输出**：将 HDR 内容输出到支持 HDR 的屏幕
- **HDR 模式**：Off / Linear HDR / BT.2020 / BT.2020 + Gamma 2.4 等模式
- **SDR 转 HDR**：Linear HDR 模式下将 SDR 内容提升到 HDR 范围
- **YUV420P 选项**：可选强制使用 YUV420P

### 6.4 截图功能
- **截图格式**：PNG / JPEG / WebP
- **截图质量**：JPEG/WebP 质量可调（默认 90），PNG 压缩级别可调（默认 7）
- **WebP 无损模式**：可选启用
- **包含字幕**：可选截图中包含当前渲染的字幕
- **截图模板**：文件名模板支持时间戳变量（默认 `mpv_snapshot_%Y%m%d_%H%M%S`）
- **媒体信息 Intent**：可选注册为系统媒体信息查看器（MediaInfoActivityAlias）

### 6.5 性能与监控
- **性能追踪**：PlaybackPerformanceTrace 追踪播放启动、Activity 生命周期、Surface 绑定等阶段耗时
- **热监控**：ThermalMonitor 监控设备温度并可在过热时降低负载
- **空闲核心回收**：3 分钟空闲后自动销毁 libmpv 核心以释放资源

## 七、播放控制与手势

### 7.1 手势系统
- **亮度手势**：左侧垂直滑动调节屏幕亮度，可选显示亮度 Pill 覆盖层
- **音量手势**：右侧垂直滑动调节媒体音量，可选显示音量 Pill 覆盖层，可选交换左右区域功能
- **水平滑动快进/快退**：可选启用，灵敏度可配置（默认 0.05）
- **捏合缩放**：双指捏合缩放视频画面，可选显示缩放级别覆盖层
- **长按倍速**：长按屏幕加速播放（默认 2x），可选显示速度覆盖层
- **平移与缩放**：启用后可平移缩放后的视频画面

### 7.2 双击与点击手势
- **双击左区域**：可配置为快进/播放暂停/自定义命令/无操作（默认快进）
- **双击中区域**：可配置为播放暂停（默认）/快进/自定义命令/无操作
- **双击右区域**：可配置为快进（默认）/播放暂停/自定义命令/无操作
- **单击中区域**：可选使用单击替代双击触发中区域动作
- **媒体键手势**：上一曲/播放暂停/下一曲手势可分别配置

### 7.3 字幕手势
- **字幕捏合缩放**：双指捏合缩放字幕文字大小
- **字幕滑动跳转**：滑动字幕文本跳转播放位置，可选启用对话框确认
- **字幕垂直位置手势**：中区域垂直滑动调节字幕垂直位置
- **字幕滑动方向反转**：可选反转字幕滑动跳转方向

### 7.4 播放控制
- **播放速度**：0.25x ~ 4.0x 可调，支持 12 个预设速度档位，长按临时加速
- **精确查找**：可选启用精确 seek（而非关键帧 seek）
- **AB 循环**：设置起点和终点循环播放
- **帧导航**：逐帧前进/后退
- **Clip 功能**：截取视频片段
- **跳过时长**：自定义快进/快退时长（默认 90 秒）
- **自定义跳过按钮**：播放器中显示自定义时长跳过按钮

### 7.5 画面控制
- **宽高比**：Crop / Fit / Stretch 三种模式，支持自定义宽高比
- **视频缩放**：默认缩放级别可配置，支持 pan-and-zoom 平移
- **画面翻转**：水平镜像、垂直翻转
- **屏幕旋转**：9 种方向模式（自由/视频/竖屏/反向竖屏/传感器竖屏/横屏/反向横屏/传感器横屏/自动）
- **自动旋转**：根据视频方向自动旋转屏幕

## 八、字幕系统

### 8.1 字幕加载
- **自动加载**：自动检测并加载同名字幕文件
- **自动启用**：加载后自动启用字幕
- **字体支持**：自定义字体文件夹，支持自定义字体族
- **ASS 覆盖**：可选覆盖 ASS 字幕样式

### 8.2 在线字幕搜索
- **搜索模式**：Wyzie 优先 / SubtitleHub 优先 / 混合模式（默认）
- **多提供商**：Wyzie、SubtitleHub、BetaSeries、Jimaku、SubDL、SubSource、Subs.ro、SubX 等
- **API Key 管理**：各提供商独立 API Key 配置
- **筛选条件**：语言、格式（SRT/ASS/VTT 等）、编码（UTF-8 等）、听力障碍字幕
- **缓存**：Wyzie 源列表缓存

### 8.3 AI 字幕
- **实时字幕**：播放时实时语音转文字生成字幕
- **AI 字幕生成**：通过 Speech-to-Text 模型生成完整字幕文件
- **AI 翻译**：将字幕翻译为目标语言（支持多语言批量翻译）
- **显示模式**：双行显示（原文+译文）或译文替换原文

### 8.4 字幕样式
- **字体大小**：默认 55，支持缩放比例调节
- **文字样式**：粗体、斜体
- **颜色**：文字颜色、边框颜色、阴影颜色、背景颜色（均支持自定义 ARGB）
- **边框样式**：描边+阴影/背景框/无背景 等样式
- **阴影偏移**：可配置
- **对齐**：左/中/右/自动
- **位置**：垂直位置 0-150% 可调
- **缩放基准**：按窗口缩放或按视频缩放
- **字幕混合**：可选将字幕混合到视频中

### 8.5 字幕同步
- **默认延迟**：可配置默认字幕延迟（毫秒）
- **默认速度**：可配置默认字幕速度
- **实时调节**：播放中调节字幕延迟和速度

## 九、音频系统

### 9.1 音轨与输出
- **音轨切换**：多音轨选择

- **声道配置**：Auto / Auto-Safe / Mono / Stereo / Reverse Stereo

- **显示模式**：双行/替换 两种显示模式

### 9.5 均衡器
- **图形均衡器**：播放器内置均衡器调节

## 十、主题与外观定制

### 10.1 主题系统
- **32 套内置预设主题**：涵盖多种配色方案
- **Material You 动态取色**：跟随系统壁纸动态生成主题色（Android 12+）
- **自定义主题编辑器**：用户可自定义主色、次色、背景色等保存为个人主题
- **深色模式**：深色/浅色/跟随系统 三种模式
- **AMOLED 纯黑模式**：可选启用纯黑背景以节省 OLED 屏幕耗电

### 10.2 壁纸与背景
- **自定义壁纸**：支持设置自定义图片壁纸
- **壁纸缩放模式**：Fit / Fill / Crop 等缩放模式
- **壁纸调节**：缩放比例、偏移量、模糊度、透明度可调
- **壁纸编辑器**：内置壁纸编辑界面

### 10.3 播放器界面定制
- **控制按钮布局**：横屏分四个区域（左上/右上/左下/右下）独立配置按钮；竖屏底部栏独立配置
- **29 种可选按钮**：返回、标题、章节、速度、解码器、HDR、旋转、帧导航、缩放、PiP、投屏、宽高比、锁定、画质、音轨、字幕、Clip、更多、当前章节、循环、随机、镜像、垂直翻转、AB 循环、自定义跳过、后台播放、环境模式、网络时间、均衡器、示波器
- **按钮背景**：可选隐藏播放器按钮背景，或强制深色背景
- **名称行数**：可选无限行数显示媒体标题

### 10.4 动画与过渡
- **控制动画风格**：默认滑动淡入淡出 / 其他风格
- **视频打开动画**：默认无 / 可选其他风格
- **导航动画风格**：默认 / 无动画
- **动画速度**：0.5x ~ 2.0x 可调
- **减少动画**：可选减少界面动画以提升可访问性
- **主题切换动画**：Telegram 风格径向揭示动画

### 10.5 导航栏与布局
- **底部导航标签页**：6 个标签（主页/音乐/最近/播放列表/网络/Jellyfin），可独立配置显示/隐藏
- **导航栏隐藏**：全屏播放时自动隐藏底部导航栏
- **安全区域窗口**：可选启用安全区域适配
- **系统状态栏/导航栏**：可选在播放器中显示系统状态栏和导航栏
- **Seekbar 风格**：粗/细风格切换，波浪形 Seekbar（可选）
- **播放器控制消失时间**：默认 4000ms 无操作后自动隐藏控制

## 十一、画中画与后台播放

### 11.1 画中画（PiP）
- **画中画模式**：视频播放时进入画中画
