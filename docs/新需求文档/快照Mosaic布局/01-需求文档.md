# 快照页 Mosaic 布局需求文档

## 1. 需求背景与目标

### 1.1 背景

当前快照页（帧捕获与收藏）支持列表和网格两种布局展示帧捕获图片。列表布局适合快速浏览文字信息，网格布局适合以等尺寸缩略图密集浏览。但随着用户积累的帧捕获增多，两种传统布局在视觉呈现上较为单调，所有图片被裁剪为统一尺寸，失去了原始截图的宽高比例特征，缺乏相册应用常见的拼贴感和视觉节奏。

### 1.2 目标

为快照页的文件夹内浏览增加第三种 **Mosaic（马赛克拼贴）** 布局。该布局下，每张帧捕获图片根据其原始宽高比以不同的大小和跨度排列：宽图横向展开、竖图纵向延伸、方图保持紧凑，整体形成错落有致的相册拼贴效果，提升浏览帧捕获时的视觉沉浸感和美感。

### 1.3 用户价值

- 保留帧捕获的原始画面比例，横屏电影截图和竖屏直播截图各有其应有的展示空间
- 相册般的拼贴排版让大量帧捕获的浏览更具愉悦感
- 三种布局自由切换，满足不同场景下的浏览偏好

---

## 2. 功能范围

### 2.1 In Scope（范围内）

- 仅针对**文件夹内**的帧捕获图片启用 Mosaic 布局
- 根据图片原始宽高比自动决定每张图在布局中的跨度和比例
- 布局切换入口集成到现有的「排序与视图选项」弹窗中，从二选一扩展为三选一
- 列数调节复用现有网格布局的手动调节能力

### 2.2 Out of Scope（范围外）

- 根页面（文件夹列表 + 未归类快照）不启用 Mosaic 布局
- 不引入按日期分组展示（如「9月16日」这样的日期标题）
- 不增加 Mosaic 专属的配置项（间距调节、角标开关等）
- 文件夹本身不参与 Mosaic 拼贴（文件夹保持现有展示方式）

---

## 3. 用户场景

### 场景一：浏览竖屏视频截图

用户截取了大量竖屏短视频的帧捕获。在 Mosaic 布局下，这些竖图自动占据纵向空间，横屏截图则横向展开，整体布局错落有致。相比统一裁剪成正方形，用户能看到截图的完整构图，浏览体验更接近系统相册。

### 场景二：混合宽高比截图的相册感浏览

用户的帧捕获库中既有横屏电影截图、也有竖屏直播截图、还有接近方形的截图。Mosaic 布局自动识别每张图的宽高特征，让宽图跨列展示、高图纵向延伸、方图保持紧凑，整体像一本自动排版的个人相册，而非整齐划一的货架。

### 场景三：布局随时切换

用户在网格布局下快速定位到目标文件夹，进入文件夹后切换到 Mosaic 布局，以更沉浸的方式回顾该视频的所有精彩帧捕获。退出文件夹后回到根页面，根页面仍保持熟悉的网格或列表布局。

## 4. 功能详细设计

### 4.1 布局切换入口

在文件夹内快照页的右上角「排序与视图选项」弹窗中，布局选择区域从现有的两个选项扩展为三个：

```
[ 列表 ]  [ 网格 ]  [ Mosaic ]
```

- **列表**：保持现有纵向列表，左侧缩略图、右侧显示视频标题、时间点、捕获日期
- **网格**：保持现有等尺寸正方形网格，所有图片统一 1:1 比例裁剪展示
- **Mosaic**：新增，图片根据原始宽高比以不同跨度和比例排列

列数调节功能在「网格」和「Mosaic」模式下均可用：自动根据屏幕宽度计算列数，最小为 3 列；用户也可开启手动调节并指定具体列数。

### 4.2 Mosaic 排布规则

Mosaic 布局在底层仍基于网格，但每张图片的列跨度和宽高比根据原始图片特征动态决定：

| 图片类型 | 宽高比特征 | 布局表现 |
|---------|-----------|---------|
| 宽图 | 宽度明显大于高度，如 16:9、21:9 | 横向跨越两列，高度按原始比例自动计算，呈现扁宽幅面 |
| 竖图 | 高度明显大于宽度，如 9:16、3:4 | 占据单列，高度按原始比例自动计算，呈现纵向延伸感 |
| 方图 | 宽高比较接近，如 4:3 ~ 1:1 | 占据单格，保持接近原始比例的展示尺寸 |

**布局约束说明**：

由于网格布局的本质是行对齐（同一行内所有单元格共享行高），当一张竖图和一张横图落在同一行时，横图会被迫撑高以匹配该行高度，可能在其上下留下视觉空白。这是 Mosaic 拼贴风格的自然表现，参考图中同样存在此类错落留白，不影响整体相册感。

### 4.3 图片卡片视觉设计

- **无圆角**：与现有网格布局保持一致，图片之间保留细间距，单张图为直角裁剪，保持照片墙的硬朗感
- **无文字覆盖**：图片上不叠加标题、时间点、日期等信息，保持纯视觉拼贴，信息在大图查看器中获取
- **间距**：图片之间的间距与现有网格布局保持一致，维持紧凑的节奏
- **背景色**：图片加载前或加载失败后，展示与现有网格一致的表面容器色背景 + 图片图标占位

### 4.4 交互行为

Mosaic 布局下的所有交互与现有网格布局保持完全一致：

- **单击**：进入全屏图片查看器，支持双指缩放、左右滑动切换相邻帧捕获
- **长按**：进入多选模式，支持批量选择、删除、移动到其他文件夹
- **多选状态**：图片右上角显示选择指示器，整体叠加选中蒙层
- **缩略图加载**：滚动时懒加载可见区域的缩略图，未加载完成前显示占位

## 6. 边界情况与异常处理

| 场景                    | 预期行为                                        |
|-----------------------|---------------------------------------------|
| 图片宽高信息缺失（存量数据）        | Mosaic 模式下降级为单格正方形展示，后台异步读取并回填尺寸            |
| 单张图片文件夹               | 正常展示，仅一张大图占据对应跨度                            |
| 大量帧捕获（500+ 张）         | 保持懒加载和虚拟化，滚动性能与网格模式一致，不一次性加载所有缩略图           |
| 图片文件被用户从系统相册删除        | 显示占位图，点击后提示「帧捕获文件已删除，是否移除记录？」               |
| 横竖屏切换                 | Mosaic 布局自动重新计算列数和每张图的跨度，保持视觉连贯             |
| 用户将列数手动调至很小（如 3 列）    | 3 列跨度的宽图会占据页面较大面积，属于正常表现；用户可通过增加列数获得更细腻的拼贴感 |
| 所有图片均为同一宽高比（如全是 16:9） | 所有图片均为宽图跨列展示，布局退化为「不等高的宽图网格」，仍优于统一裁剪        |
| 网络视频截图原视频为竖屏          | 正确识别为竖图，纵向延伸展示，不被错误裁剪为方形                    |

## 7. 非功能需求

### 7.1 性能要求

- Mosaic 布局下加载 1000 张帧捕获时，首屏渲染时间不超过 500ms
- 滚动帧率保持 60fps，缩略图加载不阻塞主线程
- 宽图跨两列展示时，缩略图分辨率需保证清晰度，必要时提升采样上限以避免模糊
- 首次从网格切换至 Mosaic 时，若存在大量存量数据需异步读取尺寸，切换动画不应被阻塞

### 7.2 用户体验要求

- 三种布局切换即时响应，无闪烁或重新加载感
- 从网格切换到 Mosaic 时，尽量保持当前的滚动位置或提供平滑过渡


### 7.3 一致性要求

- Mosaic 布局遵循应用现有的 Material3 主题、间距规范、动画风格
- 图片间距与现有网格保持一致，不引入新的间距_token_
- 大图查看器、多选模式、操作菜单等复用现有实现，行为完全一致

## 8. 待决策事项

| 事项 | 当前假设 | 备注 |
|------|---------|------|
| 宽高比阈值 | 宽图：ratio > 1.5；竖图：ratio < 0.7；其余为方图 | 可根据实际视觉效果微调 |
| Mosaic 模式图标 | 使用 Material 图标库中的拼图/马赛克风格图标 | 需与现有列表、网格图标风格统一 |
| 存量数据回填时机 | 首次以 Mosaic 布局浏览该文件夹时触发异步回填 | 也可改为应用升级后后台统一扫描 |
