质感语言 · 海拔规则

  • 全局纸纹噪点（7% 颗粒）
  • 卡纸浮起 --raise → 卡片 / 胶囊 / 迷你键
  • 纸槽内凹 --inset → 输入槽 / 滑轨 / 激活 Tab
  • 实体键台阶 0 Npx 0 → 仅矩形可按压键
  • 圆形键（FAB / 播放键）= 软浮双层投影
  • 台阶 = 可按压；Logo = 珐琅软浮徽章
  • 叠纸卡片错位 = 故意的叠纸隐喻

悬浮纸坞（参考图转译 · 紧凑版）

  • 坞宽 286 · 高 58 · 圆角 18（比例 ≈0.31）
  • 非激活键 = 仅图标；激活 = 内凹槽 + 右侧文字
  • 激活键 flex-grow 1.85 · 文字宽 38px
  • 图标与文字间距 5px · 留白收紧
  • 切换零跳动 · 按压缩放反馈保留

快照 · 相册语言

  • 文件夹 = 照片小叠：四张微旋 + 顶张山日画面
  • 顶张与 Tab 图标同语义：Tab 单张 → 文件夹一叠
  • 文件夹行不显统计 · 详情页顶栏显张数来源
  • 图片网格 = 正方形相册规格（≠ 视频 16:10）
  • 角标 = 画面在原影片中的时间点 + 播放三角
  • 详情 = 拍立得 + 胶带 + 定位时间轴
  • 跳转回播 = 朱砂实体键（真实定位播放器）
